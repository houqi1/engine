# 连通 hut 不断裂：收敛停滞及修复（2026-09-28）

## 面板能直接确认的事实

用户截图中的关注对象仍为一个连通结构。面板有 5 个应力实例，但关注对象的
actor/binding 均为 1；不能把这个现象归因于“上部独立碎块丢失载荷”。

- 33855 fines，质量 20313.453 kg，7880 nodes，16643 bonds，没有 world bonds。
- 强度 S=4 MPa；max T/C/S 为 3.14 / **23.0** / 2.57 MPa。
- 状态为 iteration budget reached；equilibrium residual=0.0189；每帧 8 次迭代。
- Candidates=0，并显示等待收敛。

因此，当前直接阻止断裂的是上一轮加入的收敛门槛。23 MPa 是压应力，不是拉应力。
颜色只反映暂态应力，不能证明当前结果已经被允许用于损伤。

## 两个独立复现的求解问题

诊断使用当前 Release 的 StructureWorld / Blast，单个整体连通结构：上下两块板，
通过 10 cm 粗、2 m 高的偏心柱连接。上部 19660.8 kg，重量约 192872 N；
总节点数 5130。四个底部支撑反力总和等于整个物体重量。材料仍为 4 MPa，agg=2。

### 1. 单精度迭代状态无法通过双精度验收

P6 用 double 重新计算残差，但 CG 迭代向量和累计 bond 解仍为 float。
在大弯矩与弱连接并存的结构上，float 的递推残差和真实残差分离，
刷新残差也不能消除累计解的舍入限制。

旧实现跑满 1800 tick 仍未通过验收，最后残差约 0.00142，Candidates=0。
柱中力已经约 192936 N，但程序不能依据该结果执行断裂。
保持相同的强度与验收阈值，只改为 double CGLS 迭代状态，8 ms 自适应预算的
对照在第 293 tick 达到约 5.53e-6，产生 1429 个候选。不同机器的预算分配会影响帧数。

### 2. 细小载荷变化不断重启 Krylov 迭代

将预算固定为每 tick 8 次，并给支撑反力施加持续 0.1% 的交替正弦抖动。
即使改为 double，精确比较 RHS 的旧续算规则也会每帧重启。
1800 tick 后仍不收敛，柱力只有正确重量的一部分。

固定载荷、double、8 次迭代时，第 455 tick 可通过；加入受控载荷快照后，
相同 0.1% 抖动的场景在第 **573 tick** 通过，残差 **2.54e-5**，
快照漂移 **0.4104%**，1425 个候选。回归随后实际提交损伤，并确认柱中 bond 的 health 已为 0。
柱中力与上部重量相差不到 1%；此比较允许快照与瞬时载荷之间的显式误差。

## 修改

- P8 使用 double 保存 CGLS 的解、残差和搜索方向。稀疏矩阵乘法和点积以 double
  执行，不显式组成正规方程矩阵；SDK 输出仍转为 float。保留 P6 的独立残差验收。
  算法背景参见 [Stanford SOL CGLS](https://web.stanford.edu/group/SOL/software/cgls/)。
- 未完成的求解继续使用同一份归一化载荷快照；逐连通分量比较当前 RHS 与快照的
  相对二范数变化，超过 **0.5%** 立即重启。拓扑、精度设置、显式 seed 或冷启动也会重启。
  求解完成后，下一轮重新采样当前载荷，不能无限期使用旧快照。
- HUD 分别显示 Equilibrium residual 与 Load snapshot drift。前者针对求解使用的快照，
  不冒充最新瞬时载荷的残差。0.5% 是单独的准静态输入更新策略，没有放宽原有数值残差阈值。
- 迭代预算扣除已收敛实例的实测耗时，再分给未完成实例，避免小碎块闲置等份预算。
- 完全未收敛的结果仍不能触发应力断裂；持续大幅变化的载荷仍可能推迟断裂。

## 验证与范围

- `blast_convergence_tests`：参考截面、刚体零模态、拆分、预算、休眠、载荷减半、NaN，
  加上上述大结构/8 次迭代/持续接触抖动/实际断柱回归。
- `blast_p4_tests`：重建与显式第二实例断裂提交。合成候选的 fixture 先建立已验收 solve，
  适应上一轮新增的断裂门槛；没有取消该门槛来让测试通过。
- `blast_e5_tests`：多实例、锚固、通用几何提取。
- 从 pinned upstream 重放 P1/P3/P4/P5/P6/P7/P8，并重复应用补丁，确认可重建和幂等。
- 真正 hut 的 `--dig-converge`：8996 个重建节点，第 814 tick（13.57 秒模拟时间）首次通过，
  残差约 2.21e-6，快照漂移 0.269%。原始结果在 `stress-double-hut.txt`。
  该诊断关闭断裂以测量求解过程，不等同于重放用户截图的切口。

双精度提高了每次迭代的成本；在当前 8 ms 预算下，复杂 hut 仍可能等待数秒到十几秒。
这里修复的是已证明的停滞与重启问题，不保证所有材料、切口形状和弯曲截面近似均已物理准确。

诊断原始文件位于 `build/hut-neck-analysis/large-neck-*-report.txt`，正式回归位于
`tests/blast_convergence_tests.cpp`。本轮修改没有提交。
