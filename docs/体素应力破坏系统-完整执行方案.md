# 体素应力破坏系统：完整执行方案

> 编制日期：2026-09-09
> 状态：技术路线已由用户确认；本文是待实施方案，不代表代码或性能验收已经完成。
> 路线：NVIDIA Blast 类结构连接反力求解 + 体素几何 + 刚体分裂。
> 优先级：承载行为正确、性能可控，其次是破碎细节；不模拟可见弹性运动。
> 保存位置：与现有《深度检索资料清单-结构力学-应力模拟-Teardown.md》并列，原资料不修改。

## 1. 执行摘要

采用较粗的结构连接图计算内部力与力矩，将连接应力与材料强度比较；连接断开后，更新承载路径和连通分量，将脱离部分作为独立刚体交给现有物理引擎。

第一版直接接入 NVIDIA-Omniverse/PhysX 仓库中的 Blast Low Level 和 ExtStress，固定一个经过验证的提交，不自行重写数值求解器，不依赖已经停止更新的 Omniverse 编辑器扩展。

最重要的产品验收场景：

1. 四根固定柱子与房顶刚性连接，承受自重而保持完整。
2. 只切断其中三根柱子的承载连接，不对剩余柱子施加直接伤害。
3. 剩余角柱传递房顶重力及偏心弯矩，危险连接应力上升。
4. 在选定的有限强度下，剩余柱子或柱顶连接断裂，房顶进入刚体下落。
5. 提高连接强度后可以撑住；增加房顶重量或偏心距离后更容易断裂。

这里不采用“剩一根柱子就强制断”的规则。结构是否断裂由载荷、图表示、支承和强度共同决定。

当前尚未指定目标项目、渲染引擎、刚体引擎和目标硬件。本文因此定义引擎无关的数据契约与执行顺序；正式编码前在 P0 固定这些接入信息，不猜测现有项目的类名或目录。

## 2. 范围与非目标

### 2.1 首版必须实现

- 固定建筑的自重承载、偏心承载和渐进坍塌。
- 连接上的拉伸、压缩、剪切以及近似弯扭贡献。
- 体素删除造成的质量、截面面积、连接和支承变化。
- 结构分裂后的质量、质心、惯量及刚体速度继承。
- 动态碎块与地面、其他物体碰撞后的二次断裂。
- 应力可视化、断裂原因记录、回放输入和性能统计。
- 固定物理时间步、可配置求解预算和小碎屑降级。

### 2.2 首版明确不实现

- 可见弹性振动、逐体素软体积分、完整动态 FEM。
- 工程级屈曲、疲劳、真实塑性铰、钢筋混凝土本构。
- 任意方向且网格无关的连续裂纹及严格断裂能守恒。
- 运行时修复、焊接、体素新增和两个已独立物体重新黏结。
- 跨平台浮点逐位确定性和多人同步协议。
- 全场景 GPU 应力求解、自动高级降阶。

应力模型属于面向实时破坏的近似反力模型，不宣称复现 Teardown 私有算法，也不作为结构安全分析工具。

## 3. 技术选型与依赖

| 项目 | 执行决定 | 原因 |
|---|---|---|
| 应力求解 | 新版 NvBlastExtStress | 已有连接反力、力矩、损伤及调试能力 |
| 拓扑分裂 | NvBlast Low Level | 可与现有刚体和渲染系统解耦 |
| 刚体与接触 | 优先复用目标项目的物理引擎 | 不因为使用 Blast 强制替换整套物理 |
| 未指定引擎时的独立验证程序 | C++、CMake、PhysX CPU 刚体后端 | 属于 P0 缺省方案，版本以实际可构建组合为准 |
| 几何 | 精细体素占据 + 面连接状态 | 支持精细挖除和不丢体积的断裂 |
| 结构粒度 | 较粗、保持拓扑的节点和 bonds | 避免逐渲染体素求解 |
| 损伤首版 | 单一结构材料、应用侧硬阈值断裂；初期拉压强度相同 | 避免面积累积损伤及弯曲拉压归类偏差 |
| SDK 内部图简化 | graphReductionLevel = 0 | 官方仍标为实验性质，先由应用构建合理粗图 |
| 旋转惯性载荷 | P3 专项验证后启用 | 不按函数名称猜测符号和物理含义 |

### 3.1 固定版本

- 从官方仓库选择可构建提交，记录 commit SHA、分支或标签、编译器、编译选项和依赖版本。
- 文档 5.0.6 与仓库 main 只作为查阅入口，不视为天然一致的二进制版本。
- 不混用旧 GameWorks 的 hardness、线性/角冲量经验因子与新版的 Pa 强度参数。
- 保存源码许可证及第三方声明；只提取或链接实际需要的模块。
- 用户试用成功的演示记录为选型证据，但仍需登记它是旧 SampleAssetViewer 还是新版 Omniverse 演示，不能把两个版本的调参混用。

### 3.2 允许的最小源码扩展

保留官方 CGNR 反力求解算法，对接入和已知近似作以下受控适配，单独维护小补丁并覆盖测试：

- 只读导出原始 bond 对应的力、力矩、拉压剪应力和图版本，用于数值验收。
- P1 关闭扩展中默认开启的 equalizeMasses，使用节点实际质量；仍保留标量惯量模型并单独验证。
- P1 增加明确的断键同步入口，保证每批 health 归零后、下一次求力前移除失效连接，即使没有 actor 分裂。
- 硬阈值在应用侧实现：对已确认超限的可破坏连接生成全额当前 health 损伤，不把 SDK 默认面积损伤量直接当作硬断裂。
- P3 增加节点广义载荷输入，允许传入偏心接触产生的外力矩。
- P5 如确有混合材料或拉压非对称需求，再提供逐 bond 判据和弯曲两侧应力恢复；不把全局参数接口伪装成逐 bond 材料支持。

上述接口属于项目计划新增的适配能力，并非当前 ExtStress 已公开的 API。首版不为这些扩展另造通用求解框架。

## 4. 总体架构与职责

```text
体素编辑 / 自重 / 接触冲量 / 工具外力
                    |
                    v
       体素几何及断面状态，应用侧权威数据
                    |
                    v
       拓扑保持的粗结构图及稳定 ID 映射
                    |
                    v
       Blast asset + family + stress solver
                    |
                    v
        内力评估 -> 损伤命令 -> actor 分裂
                    |
                    v
       几何归属、碰撞、质量和运动状态更新
                    |
                    v
       刚体运动与接触 -> 下一物理步的载荷
```

建议模块划分仅用于定义职责，不要求每一项都成为独立框架：

| 模块 | 负责 | 不负责 |
|---|---|---|
| VoxelGeometry | 占据、材料、切割、面连接、几何归属 | 数值应力求解 |
| StructureGraph | 聚合、连接截面、稳定 ID、dirty 范围 | 刚体接触积分 |
| BlastAdapter | 资产构建、索引映射、加载荷、求解、断裂通知 | 直接修改世界渲染对象 |
| PhysicsBridge | 接触采集、坐标转换、刚体创建和替换 | 再次施加已经求解过的碰撞冲量 |
| DestructionScheduler | 固定步执行、任务预算、版本验证、事务提交 | 以距离或支撑数量替代应力判据 |
| DebugAndTests | 应力图、计时、事件、回归和输入记录 | 成为生产模拟的隐藏依赖 |

### 4.1 必须维持的不变量

- 一个结构节点内部不能存在已经断开的多个体素连通分量。
- 已经断裂的面连接不能因为重新分块或重建 asset 自动恢复。
- 所有结构节点的体素归属无重复，质量不会因 actor 分裂而增加或消失。
- 只有真实锚固连接能提供世界固定反力，普通接触不升级成焊接。
- 同一接触事件在动量通道中只处理一次，在结构损伤通道中只消费一次。
- SDK 数组索引不是持久 ID，所有异步结果必须带 topologyEpoch 和 loadEpoch。
- 同一个 family/stress solver 不允许被两个线程同时修改；首版按 family 串行，不同 family 可并行。

## 5. 数据模型、单位与坐标

### 5.1 应用侧权威状态

| 对象 | 必需字段 |
|---|---|
| 体素块 | 整数坐标、占据、materialId、ownerComponentId、被切断的面状态 |
| 结构节点 | stableNodeId、所属体素区域、体积、质量、asset-local 质心、材料分区 |
| 结构连接 | stableBondId、两端 stableNodeId、面集合、中心、法向、几何面积 A_geo、损伤 d |
| 锚固 | 被连接节点、世界连接的几何位置、不可断标志；独立有限强度留到 P5 |
| 结构分量 | componentId、节点集合、实际锚固集合、刚体句柄、asset 坐标变换 |
| SDK 映射 | nodeId 到 chunkIndex/graphNodeIndex；bondId 到 SDK bondIndex；反向表 |
| 外载荷快照 | 物理 tick、事件 ID、持续/冲击类型、作用点、力/冲量、原始子步时长、当时坐标变换、消费状态 |
| 调度状态 | topologyEpoch、loadEpoch、pendingDamage、求解状态、dirty 原因 |

应用保存的 d 表示既有连接损伤，范围为 [0, 1]。首版硬断裂通常只有 0 和 1；为体素切割和后续损伤扩展保留明确定义，不预先实现复杂材料系统。

### 5.2 单位约定

统一使用 m、kg、s、N、N·m、Pa。若游戏坐标不是米，只在适配边界转换，不将游戏单位直接传入 SDK。

```text
体积 V: m^3
密度 rho: kg/m^3
质量 m = rho * V
完整面面积 A_geo = n_faces * voxelSize^2
剩余有效面积 A_eff = A_geo * (1 - d)
强度: Pa = N/m^2
接触平均力 F = J / delta_t_physics
```

新版应力扩展将可破坏 bond health 解释为剩余有效面积。按重排后的 SDK bond 顺序填充 NvBlastActorDesc::initialBondHealths 为 A_eff，不使用无量纲统一 health=1 代替所有截面面积，不写 SDK 内部只读指针。

不可断锚固使用固定版本规定的不可破坏 health 标记，该标记与应用侧真实面积分开存储，不参与面积/损伤换算。首版不通过伪造更大截面面积来实现独立更强的锚固材料。

几何挖除减少 A_geo，不等于再次增加 d；避免同一次切割把有效面积扣两遍。首版强度固定，禁止为了“调出效果”同时任意改变单位、密度和 health 语义。

### 5.3 坐标约定

- 体素和结构几何以结构 asset-local 坐标存储。
- 刚体质心坐标系与 asset 坐标系分开记录；actor 分裂后不假定两者原点相同。
- 世界接触点用逆刚体/asset 变换转换，力和力矩只旋转，不附带平移。
- 负坐标体素、偏离原点的建筑、分裂后转动的碎块都纳入测试。

## 6. 结构图生成与体素编辑

### 6.1 初始构建

1. 先用手工柱子和房顶节点验证力学，再加入体素聚合，避免几何错误与求解错误混在一起。
2. 体素版本从规则粗格开始，候选聚合尺度为 2、4、8 个体素边长，4 只作为初始实验值。
3. 每个粗格内部按材料和未断开的六邻域面连接求连通分量；不同分量不能强行合并。
4. 在粗格边界统计实际仍黏结的接触面，建立节点间连接和有效面积。
5. 柱身沿高度保留多个节点，房顶保留足够的水平分布，不能把整栋建筑合成一个节点。
6. 薄柱、薄墙、洞口、剩余细连接优先保留分辨率；相隔空隙但包围盒相邻不建立 bond。
7. 对面积分散、截面不规则的连接记录误差风险；首版可进一步拆节点，不盲目用一个等效面表示所有情况。

仅边接触或角接触不产生材料连接。渲染体素分辨率与结构分辨率分开设置；聚合收益必须以实际节点和连接数统计，不能直接宣称体素缩减倍数就是性能提升倍数。

### 6.2 SDK asset 是固定图，不是可任意编辑图

普通 bond 失效使用 Blast 的 fracture/split 路径。运行时删除体素若改变节点数量、质心、连接中心或支承布局，则应用重建受影响的结构资产。

几何以“受影响 actor 范围”重算，但首版 SDK 退役采用正确性优先的“受影响 family 整体替换”。只调用 notifyActorDestroyed 或 NvBlastActorDeactivate 不会保证旧应力图中该 actor 的正 health 连接被清除，不能把这两个通知当成动态删节点 API。

当旧 family 还有其他活跃 actor 时，为全部活跃 actor 分别构建新的 compact asset/family；未编辑 actor 复用应用侧几何和状态，避免重新扫描全部体素。全部准备好后统一替换旧 family。这会有额外成本，P5 根据实测再考虑活跃节点过滤和局部 solver 重建，不在 P4 依赖尚未实现的过滤能力。

重建事务：

1. 固定拓扑与载荷版本，取得该 actor 的体素、面断裂、材料、质量和运动状态快照。
2. 在 dirty 区域及一层边界邻域重算体素连通性和连接面；检查粗节点是否需要拆分。
3. 从应用侧权威状态构造新节点/连接；用稳定 ID 和面归属迁移既有断裂与损伤。
4. 未变化连接精确迁移；旧面完全断裂的区域禁止重新连上；无法确定来源时记录并拒绝静默恢复为满强度。
5. 构建新 asset、family、actors、stress solver 和新碰撞表示，重新建立 SDK 排序映射。
6. 为旧 family 的其他活跃 actor 同样生成紧凑替代 family，精确保留其几何、断面、质量、运动及载荷状态；不把退役 actor 留在旧 solver 继续求解。
7. 在物理安全点检查版本，原子替换整个旧 family 对应的活跃 actor 集合，继承速度场，按第 10 节处理未消费冲击。
8. 旧 family/asset/solver 在无任务和回调引用后释放；新图不用旧图维数不匹配的热启动缓存。构建失败则不提交该编辑事务。

P4 不实现运行时节点合并、修复或焊接。碎块彻底退出结构模拟后释放其不再使用的资源；空 family 单独清理。

### 6.3 断裂落到体素几何

- bond 断裂映射到应用面集合，将材料黏结标记为断开，不默认删除一层体素。
- 分裂后不同 owner 的体素面应成为可见表面；网格生成不能继续跨 owner 隐藏该面。
- 首版只允许沿所建连接代表的面断裂，承认最小破碎粒度受结构节点限制。
- 后续局部细化必须先重建局部节点和连接，再让应力决定细断裂，不能事后随意切开完整节点。

## 7. Blast 接入步骤与生命周期

### 7.1 构建路径

1. 填充 NvBlastChunkDesc 与 NvBlastBondDesc，正确设置 support 覆盖。
2. 用 SDK 的覆盖检查、重排序工具确保合法描述，并记录所有重排映射。
3. 用 NvBlastCreateAsset 建立资产，按所选版本要求分配和对齐内存。
4. 创建 family 和初始 actor，设置每条 bond 的实际初始有效面积。
5. ExtStressSolver::create(family, settings)。
6. 按 graphNodeIndex 调用 setNodeInfo；均匀密度且已确认几何正确时可用 setAllNodesInfoFromLL。
7. 对所有初始 actor 调用 notifyActorCreated。
8. 将每个 actor 映射到一个刚体或固定对象，质量与碰撞由应用管理。

### 7.2 每次求解

1. 将该轮完整外载荷快照加入 solver，包括仍存在的重力和对应接触载荷。
2. 调用 update，读取 converged、线性残差、角向残差和超限连接数。
3. 数值合格后调用 generateFractureCommands 或 generateFractureCommandsPerActor 获取首版超限候选。
4. 深拷贝命令，将每个确认超限且可破坏的 bond 的损伤量替换为其当前全部 health，再应用；生成器返回的内部缓冲会在下一次生成调用后失效。
5. 通过 NvBlastActorApplyFracture 应用，按需 NvBlastActorSplit。
6. 正确通知旧 actor 销毁与新 actor 创建；具体通知顺序根据固定版本示例验证，销毁通知不得访问已经释放的对象。
7. 从实际 fracture 结果更新应用面断裂状态、actor 归属和刚体状态，不只按请求推测成功。
8. 无论是否产生新 actor，只要有连接由正 health 变为零，就标记应力拓扑 dirty，并在下一次求力前同步移除。SDK 默认路径可能延迟到应力恢复阶段才清理无 split 的断键，本项目不依赖该顺序。

update 会消费/清空内部加载状态；重复求解不能假定上一轮的力还在。每一轮必须从明确的载荷快照重新装载。

### 7.3 默认近似的处理

新版扩展默认有质量均衡、连接居中、等体积球标量惯量近似。节点输入先按实际质量换算为加速度，质量均衡后再恢复反力会改变不同质量节点的有效载荷；增加迭代不能消除这种模型偏差。因此 P1 生产基线关闭 equalizeMasses，并验证不同质量节点的总支反力与自重相符。

连接居中和标量惯量先保留并记录限制，原版配置仅用作对照。高收敛精度下若仍出现偏心力矩丢失或角柱测试不通过，先查载荷和支承，再逐项评估这些近似。所有补丁都要跑完整基准，不能只针对一栋楼调参。

SDK 当前弯曲应力恢复把弯曲幅值加到轴向应力的同一符号一侧，可能把弯曲两侧的拉压合并为单一模式。首版因此令拉伸与压缩强度相同，暂不声称支持弯曲下真实的拉压非对称材料；P5 扩展见第 9 节。

## 8. 载荷、支承与刚体耦合

### 8.1 自重与锚固

对每个真实质量节点施加 m_i * g。固定建筑通过 world bond 或经验证的固定节点传递反力。

P1 的角柱测试明确使用柱脚固定、柱顶与房顶刚接。world 锚固使用明确不可断标志，柱身保留可切割和可受力断裂的连接，避免目标柱身尚未承载就整体脱锚。T07 通过切断锚固上方的可断连接释放物体，不向不可断标记无限加伤害。

SDK 的共享 world 节点通常放在 asset 原点，不代表每个锚固的实际空间位置。首版对不可断 world bond 不使用其应力作为失效判据，支反力从连接反力读取。P5 若启用有限强度 world bond，必须按该 bond 的实际位置与动态节点质心定义方向和有效长度，处理退化长度，不能用共享 world 节点到节点的距离计算弯曲强度。加入仅更换 asset-local 原点而物理几何不变的测试。

最后一个 world bond 断开后必须转换为动态分量。均匀重力下的无预应力自由体应无新增准静态自重内力，不能给它临时补一个假固定节点。

### 8.2 普通接触不是锚固

地面支承、碎块堆叠和工具碰撞由刚体接触求解器提供法向及摩擦冲量。接触不能提供任意拉力，不能被简化成六自由度固定。

固定对象承受其他物体重量时，也要采集对它的接触反作用载荷；如果引擎不报告静态侧冲量，需要在 PhysicsBridge 补齐读取路径。

### 8.3 接触冲量到结构载荷

```text
F_avg = J_contact / delta_t_contact
tau_at_node = (contactPoint - nodeCenter) cross F_avg
```

- 按物理子步采集本次已施加的净冲量，包含需要的摩擦贡献。
- 不叠加每个迭代的累计冲量，也不把 warm-start 总值重复当成新冲量。
- 对同一接触的双方提供相反载荷，使用该双方各自的局部坐标。
- 多点映射至少保持合力与合力矩；不能仅保持合力。
- 单次冲量不能确定真实峰值应力，首版使用固定子步平均力，并明确其模型含义。

当前公开的最近节点 addForce 入口不能完整保留偏心接触力矩。因此 P3 必须二选一并验收：为 ExtStress 的节点输入增加广义力矩通道，或在足够多且几何非退化的邻近节点上构造守恒合力/合力矩的等效力系。默认选择最小广义力矩扩展，不使用虚构的现成 addTorque API。

底层使用标量/均衡惯量的近似仍存在；载荷通道完整不代表惯性分配自动达到工程精度。单侧撞击、纯力偶、不同质量块和旋转杆需单独标定。

### 8.4 动态与重复加载规则

刚体引擎负责位置和速度积分；结构求解只评估内部承载，不能把同一碰撞冲量再施加一遍给刚体。

持续接触在每个固定物理步重新采样。单次撞击通过事件 ID 消费一次；同一步的结构重分配轮次可重用同一载荷快照做平衡评估，但不能累积成多次动量输入或重复时间损伤。

断裂并更换碰撞体后，旧接触分布可能已无效。此时终止当前接触载荷快照的级联轮次，等待下一物理步重新求接触，不把旧支承力永久留给已脱离碎块。

getExcessForces 属于可选效果通道，首版关闭。它不等于严格弹性能释放；若后续启用，须在断裂后、下一 update 前读取，并单独记录能量/动量影响。

## 9. 材料、断裂与时间策略

### 9.1 首版材料策略

先支持一种结构材料，拉伸与压缩强度相同，剪切强度独立；这是对 SDK 弯曲拉压归类近似的主动限制。只给视觉上不同的材料赋色，不冒充已经支持混合结构材料。

ExtStressSolverSettings 的强度是 solver 级参数，不是每条 bond 独立参数。混合材料必须通过 P5 的显式逐 bond 判据扩展实现，不能把相互承载的材料拆成互不交流的 family 来绕过。

首版将各模式的 elasticLimit 设为应用强度 S，fatalLimit 可设为 2S，仅用于 SDK 的候选生成与调试显示。应用对候选做硬阈值处理：应力严格超过 S 则生成扣除当前全部可破坏 health 的命令，否则不扣；以实际 fracture 结果更新状态。应用 UI 的利用率用 stress/S 显示，不把 SDK 的 elastic/fatal 颜色百分比直接解释为利用率。

不能仅通过 elasticLimit == fatalLimit 实现硬断裂：核查的实现中，阈值差为零时仍可能按超限量生成部分面积损伤。测试必须覆盖恰好达到阈值、仅略高于阈值、同一载荷重复生成三种情况。

P5 如需拉压非对称，在诊断导出基础上分别恢复近似截面两侧：s_t=max(0,s_n+b)、s_c=max(0,-s_n+b)，其中 s_n 是未叠加弯曲的轴向应力，b 是现有模型的非负弯曲幅值。再由应用遍历有效连接并按各自强度生成命令，不能继续用旧版单侧 getOverstressedBondCount 作为是否评估的前置门控。这仍是简化截面模型，不是完整 FEM。

### 9.2 渐进坍塌不等于累积微损伤

即使只有硬阈值，仍可通过“断一批连接、重新求力、再断下一批”产生渐进坍塌。

首版不启用 elastic/fatal 间的面积逐次递减。若后续开启，必须固定损伤评估频率，或显式引入含物理时间步的演化律；调整迭代次数和渲染帧率不能改变材料寿命。

### 9.3 收敛门控

- 每次求解记录 converged 和残差；不收敛时不产生新的应力断裂。
- 拓扑/载荷未变化时可继续以热启动提高精度，但下一 update 仍需重新装载同一份力。
- 超过延迟预算时进入诊断状态，提高该结构优先级或用更高预算参考求解，禁止退化为随机断裂。
- 非有限数、零面积、非法法向或损坏映射直接拒绝提交，并输出可回放输入。
- 同一轮以稳定 bond ID 排序提交断裂；减少遍历顺序对结果的影响，但不保证跨平台位级一致。

## 10. 固定步执行与异步安全

### 10.1 首版采用的耦合顺序

使用一阶分区耦合：刚体先完成一个固定步，再用该步接触载荷评估结构，断裂结果影响下一物理步。对于同 tick 内完成的已准入任务，基础耦合延迟约一个物理步；预算不足或未收敛引起的额外队列延迟单独统计，不能承诺所有任务最多只延迟一步。这不是完全同步的接触-断裂联合求解。

```text
fixedTick(dt):
    在安全点提交有效的体素编辑和已准备好的几何事务
    刚体引擎推进 dt，收集本步净接触冲量
    建立带版本和事件 ID 的结构载荷快照
    标记支承、载荷或拓扑变化的结构为 active

    对预算允许的 active family:
        加载该轮完整载荷
        stress.update()
        如果不收敛：保留待求状态，不产生应力伤害
        否则生成并深拷贝断裂命令
        校验版本并应用命令，更新面断裂和 actor 拓扑
        若边界/接触仍有效且预算允许：进入下一结构平衡轮
        否则等待下一固定步重新采样

    原子提交新刚体、碰撞和渲染归属
    记录计时、残差、断裂事件和输入消费状态
```

### 10.2 休眠条件

结构无拓扑变化、无显著载荷变化、已收敛且无超限连接时才可缓存结果。一个“还有超限连接但预算用完”的结构不能被休眠。

持续旋转、接触变化、重力方向变化和外部工具作用都必须唤醒。P1-P3 先逐固定步求解验证正确性，P5 再启用事件驱动优化。

### 10.3 载荷快照与异步规则

P1-P3 的正确性基线同步完成每个载荷快照，再进入下一物理步；不先引入复杂的跨步队列。P5 启用延期处理时采用以下明确策略：

- 持续载荷使用最新 loadEpoch；旧持续载荷结果不可提交到更新后的边界。
- 单次冲击保存为不可变事件快照，保留原始 dt、双方冲量、接触点与当时变换；不能把积压冲量相加后除以当前一步 dt。
- 每个冲击求解按自己的 snapshotId 校验，而不是因为下一 tick 的持续载荷变化就自动丢弃；它始终作用于记录时的拓扑版本。
- 拓扑将变化但旧冲击尚未评估时，首版生产策略是优先同步排空该 actor 的待评估冲击再提交拓扑，允许并记录超预算；不把旧冲击任意迁移到新碎块后重新施加平均力。
- 如果回放/工具明确取消旧冲击，必须记录取消原因；正常运行不得静默漏评。
- update 是一次不可任意中断的调用，迭代上限不是严格的毫秒抢占。调度按预估成本准入，实际超预算必须记录，不伪装成硬实时保障。

- 几何重建可以后台准备，但世界状态仅在物理安全点修改。
- 结果绑定 topologyEpoch 以及对应 loadEpoch 或 snapshotId；过期映射禁止提交，不能直接套到新节点索引上。
- 编辑以事务提交；后台未完成时不先发布与碰撞/结构不一致的权威几何。UI 可以显示编辑预览。
- 已脱离碎块的碰撞体不可以因预算不足被删除后留空；先完整准备低复杂度有效碰撞，再原子替换。
- 记录未消费冲击和排空队列耗时；长期队列增长视为性能验收失败，不通过删除关键冲击来凑帧率。

## 11. 分裂后的质量、速度与碰撞

### 11.1 质量属性

质量、质心和完整刚体惯量从实际归属体素计算。惯量包括每个体素自身惯量及平行轴项，不把体素全当成无尺寸质点。

SDK 求解代理的标量惯量近似与刚体后端的真实惯量是两层概念，不用前者替代后者。

### 11.2 速度继承

```text
v_child = v_parent + omega_parent cross (com_child - com_parent)
omega_child = omega_parent
```

质量划分一致且没有删除几何时，用此规则保持原刚体速度场。体素被工具直接删除时，把被移除的质量和其携带动量单独记账，不要求“剩余物体动量等于删除前总动量”。

首版不额外给碎块添加爆开速度。未来若添加表现冲量，应明确标记为非守恒效果并单独配置。

### 11.3 碰撞策略

- 优先使用项目已有的体素碰撞或缓存的粗块凸体/盒体组合。
- 首版不在每次断裂时对整块建筑重新做昂贵的全局凸分解。
- 空洞、狭窄通道和薄墙不能被简单包围盒全部填满而改变支承行为。
- 新碎块之间不能因碰撞形状膨胀形成深度重叠；配置接触偏移并做出生穿透测试。
- 小碎块可以停止应力求解，但仍作为普通刚体保留承重；只有明确不参与玩法承载的装饰碎屑才可降为粒子。
- 承重块、可交互块和仍有关键支承关系的块不因尺寸小就被丢弃。

## 12. 性能预算与测量

以下数字是待验证的工程目标，不是 NVIDIA 或 Teardown 的已测性能。

### 12.1 初始配置

| 参数 | 初始值或策略 | 验证方式 |
|---|---|---|
| 固定物理步 | 1/60 s | 渲染 30/60/120 FPS 时保持相同输入 tick |
| 结构节点聚合 | 边长 4 个体素起步，测试 2/4/8 | 对比拓扑、断点和耗时 |
| graphReductionLevel | 0 | 先不使用 SDK 实验简化 |
| 求解迭代上限 | 25 起步，扫描 25/50/100/200 | 依据残差与断裂载荷收敛选值 |
| 每步结构平衡轮数 | 先限制 2 轮，可配置 | 达到上限不得重复施加冲击或损伤 |
| 新增结构系统 CPU 预算 | 单栋典型场景 p95 <= 3 ms，p99 <= 6 ms | 包含图更新、应力、split、碰撞构建和提交 |
| 典型普通编辑到提交 | p95 <= 50 ms | 指稳态目标场景，不覆盖任意规模瞬间全毁 |
| 总画面目标 | 60 FPS | 需另计现有渲染、刚体步进和其他系统 |

并行情况下同时记录 CPU 总工作量与关键路径墙钟时间；不能把二者混用。P0 登记 CPU 型号、线程数、内存、编译配置和刚体后端，未登记前不签署性能达标。

### 12.2 基准矩阵

| 场景 | 初始结构节点规模 | 重点 |
|---|---|---|
| 微型角柱/悬臂 | 10-200 | 正确性、参数与收敛 |
| 小房间 | 1,000 左右 | 体素编辑和局部断裂 |
| 单栋建筑 | 5,000-10,000 | 常规 CPU 预算 |
| 多栋或大建筑 | 50,000 左右总节点 | 调度、并行、休眠 |
| 坍塌压力场景 | 单独记录碎块和接触对数量 | 瓶颈是否转移到刚体接触 |

节点规模只是测试档位，不是实时能力保证。对每档记录实际 bonds、节点质量跨度、活跃 family 数和接触点数。

### 12.3 必须统计

- 几何更新、图构建、asset 创建、应力求解、断裂应用、连通划分、碰撞构建和提交各自耗时。
- p50/p95/p99、最大单次停顿、峰值内存、连续编辑后的常驻内存。
- 迭代数、残差、未收敛次数、活跃节点/连接、断键数、刚体数和接触对数。
- 编辑排队延迟、过期结果数量、未消费接触事件数量。
- 不计资源加载的稳态记录，与首次加载和整栋瞬毁的最坏情况记录分开。

### 12.4 优化顺序

1. 保持拓扑的合理粗化，避免每个渲染体素进入求解。
2. 复用内存、描述数据、碰撞子形状和热启动。
3. 稳定结构休眠，不同 family 并行。
4. 减少受影响 family 替换的构建成本；必要时实现过滤已退役节点的局部 solver 重建，再缩小替换范围，保留全局载荷传递。
5. 小碎屑退出结构模拟，限制表现型碎片数量。
6. 在实测瓶颈明确后才考虑矩阵优化、更复杂降阶或 GPU。

不能为了满足预算让剩余角柱永远不算应力，或把未收敛结果直接用于断裂。

- [ ] 实现面断裂的权威持久状态，不靠厚层删体素表现裂缝。
- [ ] 实现受影响 actor 的几何更新、旧 family 全部活跃 actor 的紧凑资产替换、索引迁移和原子提交。
- [ ] 编辑更新质量、连接面积、质心、法向、支承与碰撞。
- [ ] 验证旧 family 所有活跃 actor 状态迁移与资源释放，不留下退役 actor 的幽灵应力图。

交付：可挖墙、切柱、削薄连接的体素交互场景。

退出条件：T14-T17 通过；既有裂缝不会重建愈合，无隔空承重，长期编辑不持续泄漏。

### P5：性能、材料扩展与生产化

- [ ] 完成基准矩阵和瓶颈分析后，按第 12 节顺序优化。
- [ ] 实现休眠、跨 family 并行、碎屑降级和稳定预算调度。
- [ ] 如产品需要，实现逐 bond 材料强度、弯曲拉压两侧判据，以及有限强度 world bond 的局部几何处理。
- [ ] 定义应用层存档格式，保存体素、断面、材料、刚体状态与配置版本，不直接依赖跨版本 SDK 内存镜像。
- [ ] 固定输入回放、参数预设、诊断导出和错误场景自动收集。

交付：集成演示、测试报告、性能报告、SDK 补丁说明和使用文档。

退出条件：核心验收全通过，目标硬件上达到约定预算；未通过的规模和近似误差明确列为限制。

## 15. 主要风险与处置

| 风险 | 典型症状 | 执行处置 |
|---|---|---|
| 新旧 SDK 混用 | 同名功能但参数含义不同 | 固定 SHA，记录用户样例版本 |
| 默认惯量/质量近似 | 偏心或不同质量块结果异常 | P1 关闭质量均衡，保留其他近似并专项验收，不盲调强度 |
| 接触力矩丢失 | 力加载成功但柱根不受弯 | 广义载荷扩展与合力矩测试作为 P3 硬门槛 |
| 固定 asset 与任意编辑冲突 | 删体素后幽灵连接 | actor 范围几何重算、family 安全替换和面状态迁移 |
| 粗化吞掉裂纹 | 断开区域继续承重 | 粗节点内连通性检查，必要时细化 |
| 接触与支承重复计算 | 重量或撞击被算两次 | 固定/接触边界分开，事件 ID 防重复 |
| 生成器缓冲失效 | 随机断错连接或越界 | 立即应用或深拷贝，再调用下一生成器 |
| 增加迭代改变损伤寿命 | 优化后物体变脆 | 首版硬阈值，后续损伤显式计时 |
| 碰撞成为主瓶颈 | 应力很快但坍塌严重卡顿 | 统计接触和刚体数，缓存子形状与碎屑降级 |
| 不收敛跨帧拖延 | 悬空结构迟迟不塌 | 超时诊断与高优先级参考求解，不用假断裂兜底 |
| 表现目标超出模型 | 需要真实屈曲或材料弯折 | 单列新需求，不把弹性 FEM 偷偷加入首版 |

## 16. 最终交付物与完成定义

- 可构建、固定依赖版本的结构破坏模块及最小示例。
- 固定四柱、单角柱、自由落体、二次碰撞、任意挖除五类演示。
- 单位、载荷、材料、图生成、碰撞与调度的参数说明。
- 自动化回归测试、输入回放和诊断场景导出。
- 目标硬件性能报告，包括应力与刚体接触分别占用的时间。
- 新增 SDK 接口及补丁列表，明确哪些仍保留官方近似。
- 不支持的行为和规模上限，不用演示中的一次成功代替全部验收。

完成定义：单角柱测试由真实载荷传递触发，断裂及刚体状态一致，体素编辑不制造幽灵连接，接触冲击不重复计数，性能目标在登记硬件和约定规模下可复现。
